# Spec Workflow MCP 拡張機能

Spec-Workflow MCPプロジェクトをワークスペースで直接管理するための統合ダッシュボードを提供するVSCode拡張機能です。

## 特徴

- **統合サイドバーダッシュボード**: VSCodeを離れることなく、すべてのスペックワークフローデータにアクセス
- **リアルタイム更新**: `.spec-workflow`ファイルが変更されると、ファイルシステムウォッチャーがダッシュボードを自動的に更新
- **プロジェクト概要**: アクティブ対アーカイブ済みのスペック、タスク、承認を示す包括的な統計
- **スペック管理**: 簡単なアーカイブ/アーカイブ解除機能を備えたアクティブおよびアーカイブ済みの仕様書の閲覧
- **タスク管理**: サイドバーから直接タスクのステータスを表示および更新
- **承認ワークフロー**: 承認、拒否、修正依頼を含む完全な承認プロセス
- **ステアリングドキュメント**: 製品、技術、構造のステアリングドキュメントを管理
- **サウンド通知**: 承認とタスク完了のための設定可能な音声アラート
- **エディタ統合**: コード内で直接承認とコメントのためのコンテキストメニューアクション
- **React + Tailwind UI**: React 19とTailwind CSS v4で構築されたモダンでレスポンシブなインターフェース

## 要件

- VSCode 1.99.0以上
- `.spec-workflow`ディレクトリ構造を含むワークスペース

## 使用方法

1. `.spec-workflow`ディレクトリを含むワークスペースを開きます
2. アクティビティバーにスペックワークフローMCPアイコンが表示されます
3. アイコンをクリックしてダッシュボードサイドバーを開きます
4. タブ付きインターフェースを使用して、以下をナビゲートします：
   - **概要**: アクティブ/アーカイブ済みスペックの内訳と最近のアクティビティを示すプロジェクト統計
   - **ステアリング**: ステアリングドキュメント（製品、技術、構造）を管理
   - **スペック**: アーカイブ管理付きのアクティブおよびアーカイブ済み仕様書を閲覧
   - **タスク**: 選択した仕様書のタスク進捗を表示および管理
   - **承認**: 完全なワークフローサポート付きの保留中の承認リクエストを処理

## アーカイブ管理

ドロップダウンメニューを整理し、クリーンに保つために仕様書をアーカイブできます：
- スペックタブで**アクティブ**と**アーカイブ済み**ビューを切り替えます
- 完了した仕様書をアーカイブして、アクティブなドロップダウンから削除します
- 必要に応じて仕様書をアーカイブ解除します
- 仕様書に保留中の承認がある場合、アーカイブ操作はブロックされます

## コマンド

- `Spec Workflow: Open Dashboard` - サイドバーダッシュボードを開きます
- `Spec Workflow: Refresh Data` - すべてのデータを手動で更新します
- `Spec Workflow: Open Spec` - 特定の仕様書を開くためのクイックピック
- `Spec Workflow: Approve` - 現在のドキュメントを承認（エディタコンテキスト）
- `Spec Workflow: Reject` - 現在のドキュメントを拒否（エディタコンテキスト）
- `Spec Workflow: Request Revision` - 現在のドキュメントの修正を依頼
- `Spec Workflow: Add Comment` - 選択したテキストにコメントを追加
- `Spec Workflow: Approval Actions` - 承認アクションメニューを表示

## 拡張機能設定

- `specWorkflow.notifications.sounds.enabled` - サウンド通知を有効にする（デフォルト：true）
- `specWorkflow.notifications.sounds.volume` - サウンド音量レベル0.0-1.0（デフォルト：0.3）
- `specWorkflow.notifications.sounds.approvalSound` - 承認リクエストのサウンドを再生（デフォルト：true）
- `specWorkflow.notifications.sounds.taskCompletionSound` - タスク完了のサウンドを再生（デフォルト：true）

## 開発

この拡張機能は以下で構築されています：
- TypeScript付きReact 19
- Webviewバンドリング用のVite
- スタイリング用のTailwind CSS v4
- ShadCN UIコンポーネント
- VSCode拡張機能API
